Calculate margins

Author

Media Innovation Group

Our goal

To find which Texas House district races were within a 5-point and 10-point margin in both the general and primary election for each year? Our data spans from 2012 to 2024.

Updates

  • April 2026: The previous calculations did not take runoffs into account. This has been remedied.
  • December 2025: Updates from the first attempt which compared the highest votes received to the lowest votes received. What we needed was the difference between those finishing 1st and 2nd in each race, which this now does. It’s a complete refactoring.

Calculate win margin

This summarise method was developed with the help of chatGPT. It’s explained here.

Expand this to see code 
reps_calcs <- reps |> 
  group_by(year, election, district) |>
  mutate(
    total_votes = sum(candvotes),
    pct = (candvotes / total_votes * 100) |> round(2)
  ) |>
  arrange(desc(candvotes), .by_group = TRUE)  |> 
  summarise(
    first_place = first(name),
    first_place_party = first(party),
    first_place_inc = first(incumbent),
    first_place_pct = first(pct),
    second_place = nth(name, 2),
    second_place_party = nth(party, 2),
    second_place_inc = nth(incumbent, 2),
    second_place_pct = nth(pct, 2),
    vote_margin = (first_place_pct - second_place_pct) |> round_half_up(2),
    .groups = "drop"
  ) |>
  mutate(
    runoff = first_place_pct <= 50,
    winner = if_else(!runoff, first_place, NA_character_)
  ) |>
  arrange(year, election, district)

Add flags

Here we add flags if the race is competitive within 5 or 10 points.

Just showing the margin and flags to check.

Expand this to see code 
reps_flags <- reps_calcs |> 
  mutate(flg_5 = if_else(vote_margin <= 5, T, F),
         flg_10 = if_else(vote_margin <= 10, T, F))

# peek at flags
reps_flags |>
  head(20) |> 
  select(vote_margin:flg_10)
